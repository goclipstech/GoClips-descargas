# GoClips: descargas

Acá se descargan los instaladores de **GoClips**, el generador de anuncios en video con IA.

**[Descargar la última versión](https://github.com/goclipstech/GoClips-descargas/releases/latest)**

- **Windows:** `GoClips-Setup-X.exe`
- **Mac con chip Apple (M1, M2, M3, M4):** `GoClips-X-arm64.dmg`
- **Mac con Intel:** `GoClips-X-x64.dmg`

La primera vez que abras GoClips, puede aparecer un aviso de seguridad porque la app todavía no está firmada:

- **Windows:** "Windows protegió su PC" → *Más información* → *Ejecutar de todas formas*.
- **Mac:** clic derecho en la app → *Abrir* → *Abrir*.
